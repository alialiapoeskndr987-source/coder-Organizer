# الهوية البصرية — coder-organizer

أصول العلامة الناتجة عن جلسة التصميم v1.24 (يولّدها `scripts/process_icons.py` محلياً من الملفات الخام).

| الملف | الاستخدام | المواصفات |
|---|---|---|
| `icon-stable-1024.png` | الأيقونة الرئيسية (النسخة الكاملة) | 1024×1024 PNG بزوايا شفافة، لمسة كهرمانية + نجمة ذهبية |
| `icon-lite-1024.png` | أيقونة النسخة الخفيفة | 1024×1024 PNG بزوايا شفافة، لمسة فيروزية |
| `play-store-icon-stable-512.png` | أيقونة قائمة Google Play للنسخة الكاملة | 512×512 RGB بلا شفافية (متوافق سياسات Play) |
| `play-store-icon-lite-512.png` | أيقونة قائمة Google Play للنسخة الخفيفة | 512×512 RGB بلا شفافية |

## رمزية التصميم
- قوسا الكود `<>` → المبرمجون.
- السهم الصاعد بينهما → النشر ونشر الإصدارات (deployment).
- الصفوف المرتبة أسفل الرمز مع علامة التحقق → التنظيم وإدارة المهام.
- القاعدة النيلية الداكنة → الثيم الافتراضي Programmer Blue.
- تمييز النسختين: الكاملة كهرمانية بنجمة، الخفيفة فيروزية — نفس التكوين بالضبط.

## أين تُطبق الأيقونات؟
مجلدات نكهات أندرويد (تُدمج تلقائياً فوق `main`):
- `android/app/src/stable/res/` → mipmap (legacy) + mipmap-anydpi-v26 (adaptive) + drawable-* foreground + لون الخلفية.
- `android/app/src/lite/res/` → نفس البنية بأيقونة اللايت.
- `android/app/src/main/res/` → نسخة stable كاحتياطي لأي بناء بلا نكهة.
